¿que es markdown?

Markdown fue creado en 2004 por John Gruber con ayuda de Aaron Swartz.
Su objetivo era crear una forma simple y fácil de leer para escribir texto que pudiera convertirse en HTML sin complicaciones.
Con el tiempo se volvió muy popular gracias a plataformas como GitHub, y hoy es uno de los formatos más usados para documentación y proyectos de programación.
